# Cyber Leveling

Cyber Leveling is an Android cybersecurity education platform that combines structured academy courses, safe sandbox labs, AI-assisted learning, and RPG-style progression.

All practical exercises are designed for authorized educational environments only. The project does not provide tools for attacking real-world systems.

## Version

**Current version:** `1.0.0`

**Version code:** `1`

## About

The app helps learners build cybersecurity skills through lessons, quizzes, simulated terminal challenges, XP, levels, ranks, streaks, achievements, and guided hints. API keys and other secrets must remain on the secure backend.

## Build

```bash
./gradlew assembleDebug
```

The generated APK is located at:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## GitHub Actions

The workflow in `.github/workflows/build-apk.yml`:

- Runs on pushes to `main`.
- Uses Java JDK 17.
- Builds the debug APK with Gradle.
- Uploads the APK as a downloadable workflow artifact.
